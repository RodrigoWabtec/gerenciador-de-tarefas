# gerenciador-de-tarefas


Atividade 3 – App “Lista de Tarefas”
Descrição:
  Desenvolver um programa de Lista de Tarefas no qual o usuário pode adicionar
  tarefas, listar tarefas, remover tarefas e marcar tarefas como concluídas.
  O projeto deve utilizar pelo menos 2 padrões, podendo escolher entre: Singleton,
  Abstract Factory, Adapter, Composite, Observer e Strategy. Veja material
  disponível no SIGAA.
  Grupos de 3 (três) alunos. Não serão aceitos grupos maiores.
  
  Funcionalidades obrigatórias:
O programa deve ter as seguintes funcionalidades:
  1. Adicionar Tarefa
    a. O usuário deve conseguir cadastrar uma tarefa contendo nome,
    descrição e status.
    b. Os status devem ser: Disponível, Fazendo e Feita.
    c. A tarefa deve ser armazenada (da maneira que preferir).
  2. Listar Tarefas
    a. O programa deve exibir todas as tarefas, indicando o status de
    cada uma.
  3. Remover Tarefa
    a. O usuário seleciona uma tarefa para excluir da lista.
  4. Alterar status da Tarefa
    a. O usuário escolhe uma tarefa e pode escolher com qual status
    quer marcar aquela tarefa.

Requisitos da entrega:
  ● Código do projeto via repositório no GitHub.
  ● Cada membro da equipe deve possuir commits no repositório.
  ● Arquivo README contendo quais, onde e como os padrões de projeto
  foram utilizados.
  ● Realizar uma apresentação, em sala de aula, da solução desenvolvida na
  data definida no cronograma.
